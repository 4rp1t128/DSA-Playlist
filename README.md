# 📚 DSA Playlist

Welcome to **DSA Playlist** — an open-source repository for learning, practicing, and contributing to **Data Structures and Algorithms (DSA)**.

The repository contains DSA problems and solutions implemented in **Python** and **C++**. Anyone can contribute their own solutions and maintain them inside their own folder.

The main goal is to create a collaborative DSA practice playlist where everyone can learn, practice, and share different approaches to solving problems.

## 🤝 How to Contribute

Everyone is welcome to contribute!

You **do not need to modify another contributor's folder**. Instead, create your own folder using your **name or GitHub username**.

### 1. Fork the Repository

Fork this repository to your GitHub account.

### 2. Clone Your Fork

```bash
git clone https://github.com/4rp1t128/DSA-Playlist.git
cd DSA-Playlist
```

### 3. Create Your Folder

Create a folder using your name or GitHub username.

For example:

```text
YourName/
```

### 4. Add Language Folders

Inside your folder, create the language folders:

```text
YourName/
├── C++/
└── Python/
```

You can contribute using one language or both.

### 5. Organize Solutions by Topic

Inside the language folder, create the appropriate DSA topic.

For example:

```text
YourName/
└── Python/
    ├── Arrays/
    ├── Strings/
    ├── LinkedList/
    ├── Stack/
    ├── Queue/
    ├── Trees/
    ├── Graphs/
    └── DynamicProgramming/
```

### 6. Add Your Problems

Add your DSA problems inside the relevant topic folder.

Example:

```text
YourName/
└── C++/
    └── Arrays/
        ├── Two_Sum.cpp
        ├── Maximum_Subarray.cpp
        └── Rotate_Array.cpp
```

### 7. Commit Your Changes

```bash
git add .
git commit -m "Add DSA solutions"
```

### 8. Push Your Changes

```bash
git push origin main
```

Or push to your own feature branch:

```bash
git push origin your-branch-name
```

### 9. Create a Pull Request

Open a Pull Request from your fork to the main repository.

## 📝 Contribution Guidelines

Please follow these simple guidelines:

* Create your own contributor folder.
* Use your **name or GitHub username** for the folder name.
* Keep **C++ and Python** solutions in their respective folders.
* Organize problems according to their DSA topic.
* Use meaningful problem/file names.
* Write clean and readable code.
* Avoid unnecessary duplicate solutions.
* Test your code before creating a Pull Request.
* Add comments when they help explain the logic.
* Do not modify another contributor's solutions without discussion.
